# Security Policy

This is a volunteer, non-commercial beta and does not promise a formal response
SLA. Please avoid publishing vulnerabilities that could execute code, corrupt
files outside the game's own settings/export directories, or expose user data.

Contact the repository owner privately through the email shown on the GitHub
profile and include:

- Affected release/commit
- Exact reproduction steps
- Impact and required user interaction
- A minimal proof of concept that contains no retail Homeworld data

Ordinary crashes, rendering bugs, compatibility issues, and malformed mission
exports should use GitHub Issues.
