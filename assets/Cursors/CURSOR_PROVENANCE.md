# High-definition Homeworld cursors

These 128x256 RGBA cursor textures are faithful restorations of the twenty
16x32 cursor sprites in the legally supplied `homeworld.big`. Their silhouettes,
colors, action symbols, transparent regions, and in-game cursor mapping are
unchanged. The restoration uses alpha-aware high-quality resampling so the
original Relic cursor language remains crisp at modern UI scales.

The game does not require these files to authorize or replace original content:
they are presentation overrides and the original installed data remains the
source and fallback.
